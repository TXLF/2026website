It’s completely normal these days that even a medium-sized project has at least a couple of databases in its infrastructure. Something as a main data storage, something for logs, something for transactional operations. 

If you get used to working through good old CLI, this database zoo doesn’t make your life easier. Every database requires its own tool. Sometimes, such tools don’t even exist. CI/CD setup for such infrastructure is a separate big story, even if you just need to run simple SQL scripts as a part of your pipeline. 

This summer, a new open-source CLI tool, dbvr, was published by DBeaver, the team that has provided an open-source universal GUI for databases for more than 10 years. Let’s take a closer look at this application and check if it’s applicable to your project.

We’ll review the main features and use cases together with the current limitations. Do you have any ideas about how a universal CLI for databases should look? Please, come and share, let’s discuss it together.
