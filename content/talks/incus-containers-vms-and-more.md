This talk serves as an introduction to the Incus project. Incus provides a powerful way to manage application containers, operating system containers and virtual machines in a single interface. While most people turn to Docker for containers or Proxmox for a more traditional hypervisor, Incus is an overlooked alternative whether it's a homelab or a production environment.
